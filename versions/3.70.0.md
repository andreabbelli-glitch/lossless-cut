## Personal Windows build

- Verify exports before reporting success: retain source audio/video offsets, check decoded boundary content, and scan all output packet timestamps for merges.
- Show necessary closed-GOP/AAC boundary alternatives in the export panel, including the added/removed content and preview.
- Smart Cut preserves track clocks, depth and colour, copies proven complete GOPs and requires explicit consent before encoding an entire selection.
- Keep editing available during verification. Preserve previous outputs and unverified intermediates; skipping a merge never authorizes segment deletion.
- Preserve every selected source's Stash UUID/profile and comment fallback, track flags, chapter titles and detected frame rate. Recognize successful attachment extraction without hiding errors. Support declared lossless audio conversions and fragmented MP4 verification.
- Keep cancelled detections from changing edits, group Undo by gesture, and correct inverse selections, numeric inputs, segment numbering and timeline indicators.
- Cancel obsolete media work, separate requests by file, reduce waveform seek/keyframe overhead, settings writes and repeated menu/context work.
- Detect filename collisions without renaming, preserve Unicode names, recover window bounds and restart naming workers after two seconds of actual execution.

Verification covers boundary content rather than full-file decoding. AAC discontinuities or ambiguous repetitive content can remain inconclusive; intermediates are retained. Physical Safari/iPhone playback is a separate pending device check. See `docs/personal-windows.md` for coverage and recovery.

## Upstream 3.70.0

- Upgrade bundled FFmpeg to 8.1 (fixes security vulnerability CVE-2026-8461)
- New "Theme" setting: Follow the OS dark/light theme, or force dark or light
- Metadata editor: Copy metadata from another track or file, apply a value to all tracks of the same type, and suggestions for common codec tags, language codes and keys
- Edited tracks and files are now highlighted, and changes can be reset per track, per file or all at once
- New setting "Video preview scaling", e.g. to not upscale small videos
- Change FPS dialog now accepts fractions like `30000/1001`
- Press Escape to leave an input field (or Enter to commit a cut time) so that keyboard shortcuts work again
- Compensate for FFmpeg seeking too early in MKV/WebM files with B-frames, which made keyframe cuts start from the previous keyframe
- Fix wrong duration when cutting files with cover art, and audio-only cuts starting off
- (Linux) AppImage no longer requires libfuse2, and LosslessCut is now available as "Open with" app
- Changed: "Create segments from keyframes" moved to the Segments menu
- Changed: HTTP API now rejects requests coming from web browsers
- Many other improvements and fixes
